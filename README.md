# Postos do Porto

Página para escolher postos de abastecimento no concelho do Porto.

- Preços em direto da [DGEG — Preços dos Combustíveis](https://precoscombustiveis.dgeg.gov.pt/), pedidos pelo navegador sempre que a página abre (com uma cópia guardada como reserva).
- Mapa de ruas © [colaboradores do OpenStreetMap](https://www.openstreetmap.org/copyright).
- Filtros por combustível e marca, seleção de postos e percurso no Google Maps.

Site: https://bhcsantos.github.io/postos-porto/
